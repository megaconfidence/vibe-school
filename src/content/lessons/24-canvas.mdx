Vibe Work isn't only a chat. Bring in files, and Work can produce real outputs: edited documents, data tables, charts, spreadsheets, small apps, and images. Most of that happens in [Canvas](/glossary#canvas), the editor that opens next to the chat. This lesson shows you each piece, then has you turn a CSV into a chart.

## Files

Drag files into the chat, or click `+`, select `Upload Files`, and pick them. You can upload several at once or a whole folder, and Work keeps them in context for the rest of the chat.

| Category | Formats |
|---|---|
| Documents | PDF, Word, PowerPoint, ODT, EPUB, RTF |
| Spreadsheets | Excel, CSV, ODS, Numbers |
| Images | PNG, JPEG, WebP, GIF |
| Text and data | TXT, Markdown, RST, LaTeX, JSON, JSONL, XML, YAML |
| Code | Python, JavaScript/TypeScript, Go, Rust, SQL, and more |
| Email | EML, MSG |
| Audio | Recordings are transcribed, then answered from the transcript |

Answers come from your files, not general knowledge. Use descriptive filenames and name the file in your prompt when you have several.

<div class="callout">
Uploads last for one chat. For documents you query again and again, use a Library or project files (see <a href="/lessons/projects">Projects</a>). Using Work in Desktop? You can also add local folders as context with <code>+</code> then <code>Folders</code>.
</div>

## Canvas

You don't need to switch Canvas on. It opens when Work decides it's useful, for example when you ask for a document, a table, or slides. To open it yourself, ask Vibe to *"open it in a canvas"*, or type `/canvas`.

In Canvas you can:

- **Edit directly**: click anywhere to fix text, code, or data by hand.
- **Ask Work**: select a passage to get the `Ask Work` field (*"make this more concise"*). Only the selection changes.
- **Track versions**: use the arrows to move between versions, see what changed, and restore an old one.
- **Preview**: the eye icon renders HTML, React components, [Mermaid](https://mermaid.js.org/) diagrams, and [Marp](https://marp.app/) slides.
- **Export**: save a deck as PowerPoint or a table as CSV or Excel.

Open several Canvases in one chat and they appear as tabs.

## Code Interpreter

Code Interpreter runs Python and TypeScript in a sandbox inside Work. You describe what you want; Work writes and runs the code:

```text
Load this CSV and show the top 5 rows, then plot sales by month.
```

The sandbox has no internet access, and pandas, numpy, and matplotlib are preinstalled. It can't fetch files from URLs, so upload the file instead.

<div class="callout">
Code Interpreter and spreadsheets are available on <strong>paid plans only</strong>. On a free plan, Work can still read a CSV and show it as a table in Canvas.
</div>

## Spreadsheets

Ask for a spreadsheet in plain language (*"Build a project tracker with task, owner, status, due date, and priority columns"*). Work builds sheets with formulas, shown in the Canvas panel. Click any cell to edit, click `Expand` to open the full Canvas view, then:

- Click the download icon to export an `.xlsx` file.
- Click `Open in Google Sheets` to continue there. Changes don't sync back.

## Mini apps

Mini apps are self-contained React apps that run in Canvas:

```text
Build a Pomodoro timer with start, pause, and reset controls.
```

The app is interactive right away. Toggle between preview (eye icon) and code (`<>` icon), refine it in chat, and click the download icon for a ZIP of the source.

## Image generation

Ask for an image in plain language, and describe the subject, style, and aspect ratio. Follow up in the same chat to edit, or upload an image to a new chat and describe changes. Daily limits depend on your plan.

<div class="callout">
For charts from real data, use Code Interpreter, not image generation. Spreadsheets and mini apps can be shared with <code>Share</code> then <code>Link accessible to anyone</code>. The link shows only the spreadsheet or app, never your chat messages.
</div>
