The model only knows what's in its [context window](/glossary#context-window): your instructions, the tools it can call, and the conversation so far. The window has a size limit, and a full window means slower, more expensive, and less focused answers. This lesson shows you how to see what's in it, how to keep it lean, and how to put the right things in.

## In your project

No new files this time. In your `vibe-todo` session you'll read the `/context` gauge, ask about `@todo/cli.py`, show the agent the test output with `!python3 -m unittest`, and compact the conversation.


## See what fills the window

Run `/context`. It shows a gauge of the context window split by category:

- **System prompt**: Vibe's instructions plus your [`AGENTS.md`](/lessons/instructions) files.
- **Tool definitions**: built-in tools, plus any [MCP](/lessons/mcp) and connector tools.
- **Skills**: the list of [skills](/lessons/skills) the model can load.
- **Conversation**: your messages, the agent's replies, and tool results.

It also shows free space and the auto-compaction buffer, marked where compaction triggers. The CLI footer has a running token counter, like `ctx 23k/600k`. Click it to open `/context`.

<div class="callout">
Every MCP server and skill you add costs context in every turn. If <code>/context</code> shows tool definitions taking a big share, turn off the servers you don't need.
</div>

## Compaction

When the conversation gets long, **compaction** replaces the history with a summary so the model can keep going.

- `/compact` compacts now. Add instructions to steer the summary, for example `/compact keep the list of failing tests`.
- **Auto-compaction** happens on its own when the conversation reaches a threshold derived from the model's context window. A top-level `auto_compact_threshold` in `config.toml` only applies to models without their own threshold (the model catalog can set one per model, and it wins). To override it for one model, add a `[[models]]` entry with just that model's `name` and `auto_compact_threshold`.

Your session and the visible conversation stay intact. Only what the model sees is summarized. To start completely fresh instead, run `/clear` (or `/new`).

## Add files with @

Type `@` to autocomplete a path, then send your message:

```text
Explain how @todo/cli.py dispatches subcommands.
```

What happens depends on what you mention:

| Mention | What the model gets |
|---|---|
| Text file | The file's content, read like the `read_file` tool (about 2000 lines or 64 KB) |
| Folder | Just the path. The agent can read or search it if it needs to |
| Image (`.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`) | The image itself |

## Images

Images work when the active model has `supports_images = true`, or when a vision-capable model on the same provider can describe them (set `vision_model` to use another provider). Otherwise the model receives `[Image]` and a link to the file.

On macOS, paste an image from the clipboard with `Ctrl+V` or `/paste-image`. You can also drag a file from Finder into the terminal. Each message can carry up to 8 images of 10 MiB each.

## Run shell commands with !

Prefix a command with `!` to run it in your shell, bypassing the agent:

```text
!python3 -m unittest
```

On Windows, use `!python -m unittest` if `python3` isn't on your path. The agent sees the command and its output as context for your next message. It's a quick way to show it a test failure or a log without asking it to run anything.

## Work alongside the agent

You don't have to wait for the agent to finish:

- **Queue a message**: press `Enter` while it works. Queued messages go out together when the turn ends. Press `Enter` again on an empty input to hand them over right away.
- **Edit the queue**: press `Up` to select a queued message, then `Enter` to edit it or `Backspace` to remove it.
- **Interrupt**: press `Escape` to stop the agent and pause the queue.
- **Todo panel**: for longer tasks the agent keeps a todo list. Press `Cmd+\` or `Alt+\` to toggle it.

`!` commands and most slash commands need an idle agent. Read-only commands such as `/status` run right away.
