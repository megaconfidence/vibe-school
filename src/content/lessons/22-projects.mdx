Every time you start a task in Vibe Work, it pulls in context: your prompt, any files, and whatever standing context you've given it. This lesson covers the four places that standing context lives: [projects](/glossary#project), [custom instructions](/glossary#custom-instructions), [Knowledge](/glossary#knowledge), and [Libraries](/glossary#library). Set them up once and you stop repeating yourself.

New to Work? Start with the [Work](/lessons/work) lesson first.

## Which one to use

| | Scope | Best for |
|---|---|---|
| **Custom instructions** | Every new task in your account | Your role, format, language, tone |
| **Projects** | Chats inside one project | Per-client or per-initiative instructions and files |
| **Knowledge** | Recalled when relevant | Facts about you that come up in chat |
| **Libraries** | Any chat you attach them to | Document sets you query again and again |

## Projects

A project groups chats and gives them shared context. You can switch from a client engagement to a launch plan without re-uploading files or rewriting prompts.

1. Click `New Project` next to the `Projects` header in the left sidebar.
2. In **Create a new project**, type a name (or pick a suggestion such as **Research** or **Writing**), optionally choose an icon, then click `Create`.

Open the project to set:

- **Tone**: pick one, or keep `Default (Global)` to inherit your custom instructions' tone.
- **Instructions**: click `Customize` to write rules for every chat in the project.
- **Files**: click `Upload files` to attach documents, spreadsheets, PDFs, or images. Every chat in the project can use them.
- **Other chats**: toggle `Include other projects' chats as context` to let Work draw on the project's other chats.

Add an existing chat by dragging it onto the project in the sidebar, or click the folder icon in the chat header and pick a project. A chat belongs to one project at a time.

<div class="callout">
Deleting a project is permanent, but its chats aren't deleted. They go back to your main chat history.
</div>

## Custom instructions

Custom instructions are a short profile Work applies to every new task. Set them from `Context` then `Instructions` in the left sidebar: choose a **Tone**, write your text under **Additional Instructions** (or click a suggestion to add it), and click `Save`. A preview on the right shows how replies will sound. Existing tasks aren't affected.

Good instructions are short and tell Work something it can't guess:

```text
I'm a compliance officer at a European bank. Reference EU regulations
(MiFID II, GDPR) when relevant. Keep responses concise and use bullet
points instead of paragraphs.
```

How they combine with other features:

- **Projects**: project instructions and custom instructions apply together.
- **Skills**: an active [skill](/lessons/automations)'s instructions take precedence over yours.
- **Connectors**: instructions shape how Work talks to you, not how tools run.

Avoid task details (put those in the prompt or a project), rules that contradict how you actually prompt, and secrets or credentials.

<div class="callout">
Custom instructions are Work's equivalent of <code>AGENTS.md</code> in Vibe Code. See the <a href="/lessons/instructions">Instructions</a> lesson for the Code side.
</div>

## Knowledge

Knowledge is what Vibe remembers about you across chats. It's the successor to Memories in the legacy Chat (your memories migrate into it) and is on by default.

- **Explicit saving**: say *"Remember that I work with TypeScript."* This is the reliable way.
- **Implicit saving**: Vibe also notices recurring details, like your preferred formats, and saves them itself.

A **read** pill shows when Vibe consults your knowledge and a **write** pill when it saves something. Retrieval isn't guaranteed: an entry is used only when it fits the request.

Manage it from `Context` then `Knowledge`. You can't edit an entry's text directly; ask in chat instead (*"Add that I now use PostgreSQL"*, *"Forget that I mentioned my location"*). To turn Knowledge off, click your organization name at the bottom left of the sidebar, then `Privacy`. Turning it off doesn't delete entries.

<div class="callout">
Sensitive personal information (health, political opinions, and similar) isn't saved unless you turn on <code>Sensitive data in Knowledge</code> in <code>Privacy</code>. Passwords, credentials, and financial account numbers are never saved.
</div>

## Libraries

A Library is a persistent knowledge base built from your documents and web pages. Uploads in a chat last for that chat; a Library works in any chat you attach it to.

1. Open `Context` then `Libraries` in the sidebar and click `New library` (or `Index website` to start from web pages).
2. Drag in files or click `Upload` (up to 100 files at once, 100 MB per file). To add a web page, click `Webpage`, enter URLs, and click `Index`. Only the page's text is indexed.
3. In any chat, click `+`, select `Libraries`, and pick one or more.

Answers include numbered footnotes linked to the source passage, and a `Sources` button lists every reference. New Libraries are private; click `Share` to add people as **Collaborator** (can edit) or **Viewer** (can use), or toggle `Entire organization`.

Learn more in the docs: [Projects](https://docs.mistral.ai/vibe/work/web/projects), [Custom instructions](https://docs.mistral.ai/vibe/work/web/custom-instructions), [Knowledge](https://docs.mistral.ai/vibe/work/web/knowledge), and [Libraries](https://docs.mistral.ai/vibe/work/web/libraries).
