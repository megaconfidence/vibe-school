Research is where Vibe Work earns its keep: it plans the search, reads the sources, and hands you a draft with citations. In this exercise, you'll research something you actually need to know, check the sources, and keep the result where you'll find it again.

## Set up the chat

1. Open [Work](https://chat.mistral.ai/work) and select **Work** in the sidebar's mode selector.
2. Switch to **think** for multi-step reasoning: the **fast/think toggle**, or a reasoning level in the model menu, depending on your account.
3. Ask for current information: Work searches the web on its own and shows **Ran a web search** steps you can expand.

## Write a good research prompt

Name the result, the sources, the audience, and the limits:

```text
Research the main open-source options for self-hosting a vector database in 2026.
Compare licensing, scaling limits, and managed offerings.
Write a one-page brief for an engineering manager. Cite a source for every claim.
```

Paste URLs into the message when you want Work to read specific pages. For a longer, multi-source report, use the built-in skill: type `/deep-research` followed by your question.

## Check the sources

When Work uses the web, you'll see a **globe icon** next to the response, **inline links** to each source, and a `Sources` button that lists them all. Open a couple and check that the claims match. Treat the brief as a draft until you have.

<div class="callout">
Web search can return outdated or incomplete content, and it can't read pages behind a login or paywall. For those, download the page and upload it as a file.
</div>

## Save and export

- **Polish it in Canvas.** Ask Work to "open this in Canvas", then edit directly or select a passage and use `Ask Work` for targeted changes.
- **Keep it in a Project.** Click `New Project` next to the `Projects` header, then move the chat into it with the **folder icon** in the chat header. Project instructions and files then apply to every future chat on this topic.
- **Export it.** Use the export button in Canvas to save the brief as a file.
- **Optional: add it to a Library.** Upload the exported file to a [Library](https://docs.mistral.ai/vibe/work/web/libraries) so later chats can search it.

## Tips

- **Narrow first.** "Solar energy" gets you a textbook. "Residential solar incentives in Germany since 2024" gets you an answer.
- **Ask for disagreement.** "Where do sources disagree?" surfaces what a summary hides.
- **Turn it into a habit.** If you'll ask the same question every week, the [Schedule a digest](/exercises/schedule-a-digest) exercise runs it for you.
