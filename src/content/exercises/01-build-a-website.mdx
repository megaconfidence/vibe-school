Time to build something you can see. In this exercise, you'll build a small website with Vibe, run it on your machine, and improve it by showing Vibe screenshots of what it made.

## What you'll build

A single page that's yours: a personal homepage, a landing page for a side project, or a page for an event. You'll start with plain HTML, CSS, and JavaScript, so there is nothing to install and no build step. If you already know Node.js, you can use [Astro](https://astro.build) instead.

## Preview it locally

Your browser can open `index.html` directly, but a local server behaves more like the real web. Python ships with a simple one:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000. Vibe can start this server for you in the background while you keep chatting.

## Iterate with screenshots

Describing a layout problem in words is slow. A screenshot is faster. Save one into your project folder and show it to Vibe:

```text
@screenshot.png The header looks cramped on a phone. Fix the spacing and make the menu wrap.
```

In the CLI, `@` attaches the image to your prompt. On macOS you can also paste an image straight from the clipboard with `Ctrl+V` or `/paste-image`. In VS Code or Desktop, ask Vibe to open the screenshot file. See the [Context](/lessons/context) lesson for more on `@` mentions.

<div class="callout">
Images only reach the model when the active model supports them or a <code>vision_model</code> is configured. Otherwise Vibe sends <code>[Image]</code> and a link to the file. The <a href="/lessons/models">Models</a> lesson covers how to switch models.
</div>

## Tips

- **Commit early.** Run `git init` before the first change. If an iteration goes wrong, `git diff` shows what changed and you can ask Vibe to restore the last commit.
- **Be specific.** "Make it look better" gets you a guess. "Use a serif font for headings and add more space between sections" gets you what you want.
- **Keep the server running.** Reload the browser after each change instead of restarting the server.
- **Try the Desktop browser.** In [Vibe Desktop](/lessons/desktop), the globe icon opens an integrated browser beside the conversation.

Learn more in the [CLI docs](https://docs.mistral.ai/vibe/code/cli/work-with-cli#reference-files).
