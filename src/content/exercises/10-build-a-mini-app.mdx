You don't need a code editor to build a small app. In this exercise, you'll describe one to Vibe Work, use it right in the chat, improve it by talking to it, and then share it or download the code.

## What's a mini app

A mini app is a self-contained React application that runs in the **Canvas** panel. Work writes the code and renders it live, so you can click buttons and fill in forms straight away.

## Build it

Canvas opens on its own when you ask for an app (if it doesn't, ask Vibe to open it in a canvas). Describe what you want, including what you see and what you do:

```text
Build a monthly budget calculator. I enter my income and my expenses by category.
Show the total spent, what's left, and a bar chart by category. Use a clean, light design.
```

Other ideas:

- A quiz with ten questions on a topic you're learning, with a score at the end.
- A tip splitter for a group dinner.
- A Pomodoro timer with start, pause, and reset.

The app appears inline. Click `Expand` at the bottom of the panel to open it in the side Canvas view.

## Iterate

Use the app, then ask for changes in the chat:

- "Add a reset button that clears all inputs."
- "Add a dark mode toggle."
- "Show a warning when expenses exceed income."

Work updates the code and re-renders it. To see the code, switch from **Preview** (eye icon) to **Code** (`<>` icon) in the top-left corner of the Canvas panel. You can edit files there too.

## Share or download

- **Share**: click `Share` in the top-right corner of the Canvas panel, toggle `Link accessible to anyone` on, and click `Copy link`. Anyone with the link can use the app. Your chat messages aren't shared.
- **Download**: click the download icon in the top-right corner for a ZIP of the source files, ready to open in any code editor or deploy to a static host.

<div class="callout">
To stop sharing, open the <code>Share</code> dialog again and toggle <code>Link accessible to anyone</code> off.
</div>

## Tips

- **One feature per message.** Small steps are easier to check and easier to undo.
- **Describe behavior, not code.** "When I click Add, the new row goes to the top" works better than naming React hooks.
- **Take it further in Vibe Code.** Download the ZIP and keep building it locally with the CLI or VS Code, like in the [Build a website](/exercises/build-a-website) exercise.
